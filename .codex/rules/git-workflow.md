# Git Workflow Rules

- Check `git status --short` before broad edits.
- Do not revert, overwrite, or reformat unrelated user changes.
- Keep commits focused when the user asks for commits; do not commit without being asked.
- Use project-local files for rules and automation. Do not change global Git hooks or global Git config.
- Before finalizing, summarize created or modified files and verification results.
- If a conflict with existing user work blocks the task, stop and ask for direction.
