# BDD: AI 回答引用来源分析与内容反哺闭环

## Feature: AI 引用来源分析闭环

作为 GEO 内容运营人员，
我希望系统能从 AI 回答中识别引用来源、分析被引用文章特征，
并将这些偏好反哺到文章生成和复测评估中，
以便生产更容易被 AI 采纳和引用的优信内容。

## Background

假如系统已存在客户资产、Prompt 库和模型可见度监测能力
并且用户已选择一个客户品牌、官网域名、竞品和监测问题
并且至少配置了一个可调用 AI 模型

---

## Scenario: 从 AI 回答中抽取引用来源

当用户发起一次模型可见度监测
并且模型回答中包含 URL、媒体名、文章标题或来源描述
那么系统应保存每条回答的原文
并且系统应抽取回答中的引用来源
并且每个来源应记录对应的问题、模型、品牌、来源 URL、来源域名、来源标题和引用片段
并且来源应关联到本次模型监测结果

验收标准：
- 有 URL 时保存为强来源
- 无 URL 但有媒体名或来源描述时保存为弱来源
- 来源抽取失败不应影响模型回答入库
- 同一回答中的重复 URL 应去重

---

## Scenario: 抓取并分析被引用文章

假如 AI 回答来源中存在可访问 URL
当系统执行来源文章分析
那么系统应抓取来源页面标题和正文
并且系统应识别媒体域名和媒体类型
并且系统应生成文章内容画像
并且系统应计算信任锚点命中情况

验收标准：
- 文章画像包含标题类型、正文长度、是否 FAQ、是否有步骤、是否有数据、是否有案例、是否有权威引用、是否有对比
- 信任锚点至少包含：客户原话、时间节点、使用场景、事实数据、身份信息、执行步骤、选择对比、权威引用、真实案例、持续输出
- 抓取失败时记录失败原因
- 已分析过的 URL 不重复抓取，除非用户手动刷新

---

## Scenario: 统计 AI 偏好的媒体和文章类型

假如系统已积累多条 AI 回答来源和来源文章画像
当用户查看“AI 引用偏好分析”
那么系统应展示来源媒体分布
并且系统应展示文章类型分布
并且系统应展示信任锚点命中率
并且系统应展示品牌与竞品被引用来源对比
并且系统应给出内容补齐建议

验收标准：
- 展示 Top 媒体域名
- 展示官网、知乎、新闻站、行业站、百科、公众号等来源类型占比
- 展示高频被引用文章结构
- 展示竞品高频引用来源
- 输出“建议新增的内容类型”和“建议补充的信任锚点”

---

## Scenario: 将 AI 引用偏好反哺文章生成

假如用户基于某个 Prompt 生成文章
并且该 Prompt 或关键词已有 AI 引用偏好数据
当系统生成文章写作简报
那么系统应带入同类高频引用文章结构
并且系统应带入高命中信任锚点要求
并且系统应要求文章围绕当前 Prompt 主问题写作
并且系统不得复制参考文章原文内容

验收标准：
- 写作简报包含推荐文章结构
- 写作简报包含必须命中的信任锚点
- 文章生成结果应保留品牌事实、官网事实和客户资料边界
- 不得编造数据、案例、奖项、客户名称
- 不得洗稿或复用参考文章独特表达

---

## Scenario: 文章发布后复测优化效果

假如用户已发布一篇由系统生成的文章
并且系统记录了发布 URL
当用户发起复测
那么系统应使用同一批 Prompt 和模型重新提问
并且系统应对比发布前后的品牌提及率、推荐率、首推率、前三率、竞品提及率
并且系统应检查新发布文章是否被 AI 回答引用
并且系统应生成优化效果复盘报告

验收标准：
- 复盘报告展示发布前后指标变化
- 首推率按品牌排名第 1 计算
- 前三率按品牌排名小于等于 3 计算
- 如果新文章被引用，应展示引用问题、模型、引用片段和来源 URL
- 如果指标未提升，应给出可能原因和下一步优化建议

---

## Scenario: AI 回答没有引用来源时的降级处理

假如模型回答没有 URL、媒体名或明确来源
当系统进行来源抽取
那么系统不应报错
并且系统应将该回答标记为“无显式来源”
并且该回答仍应参与品牌提及率、推荐率、排名和竞品提及统计

验收标准：
- 无来源回答不进入来源文章抓取队列
- 无来源回答仍保留在模型回答明细中
- 统计页面应展示“无显式来源”占比

---

## Scenario: 用户查看单个 Prompt 的引用偏好

假如某个 Prompt 已有多轮模型监测结果
当用户打开该 Prompt 的引用偏好详情
那么系统应展示该 Prompt 下最常被 AI 引用的来源
并且系统应展示该 Prompt 下竞品出现情况
并且系统应展示推荐写作结构
并且系统应支持一键创建文章生成任务

验收标准：
- 能看到该 Prompt 的历史回答
- 能看到该 Prompt 的来源域名排名
- 能看到该 Prompt 的信任锚点缺口
- 创建文章任务时自动带入 Prompt、关键词、推荐结构和信任锚点要求
